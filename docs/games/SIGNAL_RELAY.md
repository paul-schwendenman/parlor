# Signal Relay

Signal Relay is a timed cooperative game for two to four players. Clear four relays together. Everyone starts with two private signals in the first relay and gets one more per relay after that.

Each antenna displays a channel and a strength. To send a signal, match the channel or differ in strength by exactly one. The signal you send becomes the next antenna face. Anyone can send at any time. If another player changes an antenna first, choose again using its new signal.

Once per relay the team can send any signal to either antenna using its shared reroute. Each relay gives the team 55 seconds to empty every hand. Clear four relays to win as a team. Running out of time ends the game.
