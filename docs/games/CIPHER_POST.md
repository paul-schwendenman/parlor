# Cipher Post

Cipher Post is a four-round deduction game for two to six players. Each round uses a fresh deck of four copies of each value from one through six.

Everyone starts with two seals. Secretly pass one to your neighbour and receive one from the other side. Pass clockwise on odd rounds and counterclockwise on even rounds. Next, privately choose a seal to expose. Exposed values become public together. Your other seal stays hidden.

Secretly guess one rival's sealed value. The seal you sent is a private clue. Reveal all guesses and sealed values together. Each correct guess earns four points. A seal earns its value for its owner if nobody guessed it. The highest total after four rounds wins, with ties shared.
